# Feiyen 需求調查表單設計（Google 表單）

> [!summary] 表單定位
> 這不是「下單表單」，而是**需求調查表**：先了解客人想做什麼，再私訊討論細節、報價。
> 客人填完 ≠ 成立訂單，表單裡要講清楚，避免誤會。
> 相關：[[Feiyen 商品表]]、[[Feiyen 手繪接案經營]]

## 流程定位
`客人填需求表` → **我看需求、私訊討論** → `報價` → `付款` → `收齊資料` → `繪製` → `交付`

---

## 表單架構（使用「區段」＋「依答案前往區段」）

```
區段 1  開場說明＋基本資料
區段 2  想做的商品  ──依答案分流──┐
   ├ 區段 3A 無臉畫圖檔            │
   ├ 區段 3B 無框畫                │  各商品區段填完
   ├ 區段 3C 鑰匙圈                ├─ 都前往區段 4
   ├ 區段 3D 生日插旗／生日立牌    │
   └ 區段 3E 紅包袋／春聯          ┘
區段 4  畫面內容（人物、寵物、背景、文字）
區段 5  時間、預算與取貨
區段 6  參考照片
區段 7  確認事項 → 送出
```

> 設定方法：在區段 2 的「想做的商品」題目右下角「⋮」→「根據答案前往相關區段」；每個商品區段的最下方，「在第 X 區段後」選「前往區段 4」。

## 區段 1：開場說明＋基本資料

**表單標題**：Feiyen 手繪｜客製需求調查表

**表單說明**（直接複製）：
```
嗨嗨～謝謝你對 Feiyen 手繪有興趣 🥰

這份表單是「需求調查」，幫助我先了解你想做的內容。
填完後我會私訊和你討論細節並報價，確認報價並付款後才算正式下單喔！

我是兼職畫家，會在 ＿＿ 天內回覆，請見諒～
填寫前建議先看 IG 精選「貼心提醒」和「客製化商品」 ✨
```

## 區段 6：參考照片

> [!warning] Google 表單「檔案上傳」的限制
> - 使用「檔案上傳」題型時，**客人必須登入 Google 帳號**才能填寫，可能讓部分客人放棄。
> - 上傳的檔案會存在你的 Google 雲端硬碟，佔用你的空間。
> **建議**：表單不收照片，改請客人「填完後用 IG 私訊傳照片」。如果想用上傳，請設成非必填。

| # | 題目 | 題型 | 必填 | 選項／說明 |
| --- | --- | --- | :---: | --- |
| 35 | 參考照片怎麼提供？ | 選擇題 | ✅ | 填完後用 IG 私訊傳給你／用 LINE 傳給你／還沒準備好 |

**區段說明文字**（直接複製）：
```
📸 參考照片小提醒
・臉部清楚、光線充足，不要有濾鏡或太遠
・全身照最好，至少要有上半身
・每位人物或寵物都需要照片，可以分開拍
・照片只用於這次繪製，不會公開或作其他用途
```

## 表單設定

**一般**
- [ ] **收集電子郵件地址**：關閉（不然客人要登入，或必須填 Email）
- [ ] **限制只能回覆 1 次**：關閉（同上，需登入）
- [ ] **允許編輯回覆**：開啟

**簡報**
- [ ] **確認訊息**（送出後顯示，直接複製）：
```
收到你的需求了，謝謝你 💛
我會在 ＿＿ 天內用你選的方式聯絡你，
如果有參考照片，可以先私訊 IG @fei.ru.yen 給我喔！
```

**主題**
- [ ] 頁首圖片用 Logo 或代表作品
- [ ] 主題色用 Logo 的奶茶色，和 IG 風格一致

**回覆**
- [ ] 「回覆」分頁 → 連結到 Google 試算表
- [ ] 「⋮」→ 開啟「收到新回覆時傳送電子郵件通知」

## 回覆試算表：加上自己的管理欄位

表單自動產生的欄位不要動，在最右邊**手動新增**這幾欄：

| 欄位 | 用途 | 建議設定 |
| --- | --- | --- |
| 狀態 | 這筆需求進行到哪 | 下拉選單：新需求／已聯絡／已報價／已付款／繪製中／已交付／未成交 |
| 報價金額 | 給客人的報價 | 數字 |
| 聯絡日期 | 什麼時候回覆的 | 日期 |
| 交件日 | 確認的交件日期 | 日期 |
| 未成交原因 | 價格、時間、沒回覆… | 文字，用來調整商品和價格 |
| 備註 | 討論過程重點 | 文字 |

> 設定下拉選單：選取「狀態」整欄 →「資料」→「資料驗證」→「下拉式選單」。
> 可以再用「條件式格式設定」讓「新需求」整列變黃色，一眼看出還沒回覆的人。

## 放在哪裡讓客人看到
- [ ] IG 個人簡介的連結（或連結頁裡的第一個）
- [ ] 精選動態新增「如何訂購」，最後一張放表單連結
- [ ] 私訊快速回覆：客人問「想訂做」時，直接貼表單連結
- [ ] 貼文結尾：「想做一張自己的？填 IG 簡介的需求表單」

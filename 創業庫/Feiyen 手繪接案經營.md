## 3. 私訊與常見問答

**目標**：客人第一次私訊時，先拿到需要的資訊，減少來回。

- [ ] 整理常見問答：價格、製作天數、流程、要提供什麼照片、可修改幾次、付款方式、交付格式
- [ ] 做成「私訊開場範本」，存成 IG 快速回覆
- [ ] 更新「貼心提醒」精選，和問答內容一致
- [ ] 之後再評估：留言關鍵字自動私訊（參考佳盈自架取代 ManyChat）

**私訊開場範本（草稿）**
```
嗨嗨～謝謝你的詢問 🥰
我是兼職畫家，回覆會稍慢，請見諒！

先麻煩告訴我：
1. 想做哪一種：無臉畫／似顏畫／Logo／姓名貼／客製商品
2. 人數（或寵物數）
3. 用途和希望的交件日期
4. 參考照片（臉部清楚、光線充足）

價格和流程可以先看精選「貼心提醒」喔！
```

## 4. 接案流程與看板

### 每一案的流程
`詢價` → `報價` → `收資料（照片、色號、文字）` → `草稿` → `修改` → `定稿交付` → `收反饋`

### Obsidian 看板（六階段）
| 階段 | 說明 |
| --- | --- |
| 洽詢中 | 已私訊、還沒確定 |
| 已確認 | 已報價、已付款或訂金 |
| 繪製中 | 已收齊資料，開始畫 |
| 待修改 | 草稿已給客人 |
| 已交付 | 定稿檔案已交 |
| 已收反饋 | 反饋已存、可放作品集 |

### 一案一筆記要記的欄位
- 客人 IG、服務類型、人數、價格、付款狀態
- 收件日、承諾交件日
- 參考照片、背景色號、要放的文字
- 修改紀錄（第幾次、改什麼）
- 客人反饋、可否公開分享

> 參考佳盈「一個合作案的一生：我只做三件事」——我只負責確認、畫、交付，其餘記錄和提醒交給系統。

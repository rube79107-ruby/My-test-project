## 6. 建議追加的欄位

| 欄位 | 為什麼需要 |
| --- | --- |
| **加價項目** | 加人、加寵物、急件最常被問，統一規則可以少回很多私訊 |
| **製作天數** | 兼職最怕被催，先寫清楚，也方便排檔期 |
| **修改次數** | 避免無限修改，是手繪接案最常見的糾紛 |
| **需要客人提供** | 一次收齊照片和資料，減少來回 |
| **最晚下單日** | 生日、節日商品有明確期限 |
| **最低訂購量** | 鑰匙圈、紅包袋等實體商品，數量少可能不划算 |
| **成本與時薪** | 找出真正賺錢的商品，不只看賣得多 |
| **使用授權** | 圖檔被拿去商用（印成商品販售）時有依據 |
| **範例作品** | 每個商品附一張代表作，可以連到 IG 貼文 |
| **狀態** | 上架中／季節限定／暫停接單，旺季爆單時可以暫停 |

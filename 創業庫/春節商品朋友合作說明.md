# 春節商品朋友合作說明

> [!summary] 合作方式：團購主（批發價）
> 朋友照原價賣，用批發價跟我訂，**價差就是朋友的分潤**。
> 朋友負責：宣傳、收單、收款、收照片、轉交商品。
> 我負責：換臉製作、送印、裁剪、黏貼、一次寄給朋友。
> 相關：[[Feiyen 商品表]]

---

## 2. 訂單彙整表（給朋友用）

可以做成 Google 試算表分享給朋友，或請朋友照這個格式整理：

| 客人名稱 | 商品 | 款式 | 數量（款） | 人數 | 加印張數 | 貼紙（A／B，組數） | 售價小計 | 照片已收 | 備註 |
| --- | --- | --- | ---: | ---: | ---: | --- | ---: | :---: | --- |
| 例：王小美 | 紅包袋 | A | 1 | 2 | 0 | A×1 | 180＋20＋60＝260 | ✅ | |
| 例：王小美 | 春聯 | B | 1 | 1 | 1 | | 150＋40＝190 | ✅ | |
| | | | | | | | | | |

**朋友要匯給我的金額** = 批發價 × 款數 ＋ 多人費用 ＋ 加印費用 ＋（貼紙售價 − 貼紙分潤）

## 3. 內部：分潤建議與試算（不給朋友看）

### 建議數字
| 項目 | 售價 | 建議分潤 | 批發價 | 理由 |
| --- | ---: | ---: | ---: | --- |
| 紅包袋（1 款 3 個） | 180 | 30 | 150 | 約 17% |
| 春聯（1 款 2 張） | 150 | 25 | 125 | 約 17% |
| 新年貼紙（1 組） | 60 | 10 | 50 | 固定圖案，製作省時 |
| 多 1 人、加印 | 20／40 | 0 | — | 額外製作成本，全額歸自己 |

- **最低訂購量**：建議一次滿 **10 款**（紅包袋＋春聯合計）才給批發價
- **朋友截單**：建議 **12/20**，比自己的 12/31 早，才有時間統一製作

### 試算：朋友一次訂 10 款，一次寄出
| | 紅包袋 10 款 | 春聯 10 款 |
| --- | ---: | ---: |
| 收到（批發價） | 1,500 | 1,250 |
| 材料 | −330 | −280 |
| 包材（只寄一次） | −50 | −50 |
| **我的淨利** | **1,120（每款 112）** | **920（每款 92）** |
| 對比自己單賣一款 | 97 | 72 |

> 運費由朋友支付，所以沒有算進成本。

### 為什麼這樣比較省時間
- 圖案是**固定款**，只要把客人照片換進去，不用每組重畫
- 同一批一起送印、裁剪、黏貼，比一張一張做快
- 收款、回訊息、轉交都由朋友處理
- 只要打包寄送一次

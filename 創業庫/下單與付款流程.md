# 下單與付款流程

> [!summary] 流程
> 討論完需求 → **傳訂單確認單** → 客人回覆「確認」→ **傳匯款資訊** → 客人匯款並提供後五碼 → **對帳後回覆** → 開始製作
> 相關：[[Feiyen 商品表]]、[[訂單系統使用教學]]

| 步驟 | 我要做的 | 後台狀態 |
| --- | --- | --- |
| 1. 訂單確認單 | 傳確認單，請客人回覆「確認」 | 已報價（填上報價金額） |
| 2. 匯款資訊 | 傳匯款資訊和付款期限 | 已報價 |
| 3. 對帳後回覆 | 確認入帳，回覆客人 | **已匯款** |
| 4. 製作 | 草稿 → 修改 → 定稿 | 製作中 |
| 5. 出貨 | 寄出並傳取貨資訊 | 已寄出 → 已完成 |

## 1. 訂單確認單（範本）

> 複製後，把 `＿＿` 換成這筆訂單的內容。價格以 [[Feiyen 商品表]] 為準。

```
🧾 Feiyen 手繪｜訂單確認
訂單編號：＿＿＿＿＿＿

【商品內容】
・＿＿＿＿＿＿　$＿＿＿
・＿＿＿＿＿＿　$＿＿＿

商品小計：$＿＿＿
運費（＿＿ 店到店）：$60
💰 應付金額：$＿＿＿

【收件資訊】
＿＿＿｜＿＿＿＿＿＿＿＿＿＿｜＿＿＿＿＿＿ 門市

【時間】
收到匯款後開始製作，約 20 天完成寄出

請確認以上內容無誤，回覆「確認」後我再提供匯款資訊 🙏
```

## 2. 匯款資訊（範本）

> 第一次使用前，先把銀行資料填好，之後只要改金額。

```
💳 匯款資訊
銀行：＿＿銀行（代碼 ＿＿＿）
帳號：＿＿＿＿＿＿＿＿＿＿
戶名：＿＿＿
金額：$＿＿＿

請於 3 天內完成匯款，匯款後告訴我：
① 帳號後五碼　② 匯款金額　③ 匯款時間
逾期未匯款，名額就不保留囉！

※ 收到全額匯款後才會開始製作
※ 開始繪製後恕不退款
```

**小提醒**
- 付款期限 3 天，避免客人佔著檔期
- 一定要請客人提供**帳號後五碼**，對帳才知道是誰匯的
- 可以考慮開一個收款專用帳戶，對帳比較清楚

---

## 3. 對帳後回覆（範本）

**對帳步驟**
1. 打開網銀或銀行 App，確認**金額**和**後五碼**
2. 到訂單後台，狀態改成「**已匯款**」
3. 備註寫：`後五碼 ＿＿＿＿＿，＿/＿ 入帳`
4. 回覆客人：

```
已收到你的匯款 $＿＿＿，謝謝 💛
開始排單製作囉！預計 ＿/＿ 前寄出，
草稿完成時會先傳給你確認～
```

> 預計寄出日 = 入帳日 + 20 天。生日商品要確認寄出日比生日早，且預留寄送時間。

## 4. IG 快速回覆設定建議

把範本存成 IG「快速回覆」，在私訊輸入捷徑就能叫出整段文字：

| 捷徑 | 內容 |
| --- | --- |
| `/確認單` | 1. 訂單確認單 |
| `/匯款` | 2. 匯款資訊 |
| `/收款` | 3. 對帳後回覆 |

設定位置：IG →「設定」→「商業工具和管理」或「創作者工具」→「快速回覆」（找不到可在設定搜尋「快速回覆」）
